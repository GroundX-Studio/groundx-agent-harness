# Harness Feedback References

This skill is part of the **GroundX Agent Harness** plugin. Reporting a defect in
the harness itself: when to offer, what a report covers, and how to file it.

A request does not need to mention reporting, filing, or a bug. Assume this skill
applies whenever the harness told an agent something untrue, or stayed silent on a
subject one of its skills claims.

## Fast Path

Read `report-template.md` before drafting anything. It is the only runtime
reference here, and it carries the whole contract.

## What To Use

| Task | Reference |
| --- | --- |
| Deciding whether something is worth reporting | `report-template.md`, "When to offer a report" |
| Recognising a contradicted assertion | `report-template.md`, "Offer when" |
| Knowing when to stay quiet | `report-template.md`, "Do not offer when" |
| Writing the narrative | `report-template.md`, "The narrative" |
| Sizing, citing, and separating fact from inference | `report-template.md`, "Writing rules" |
| Seeing a finished report | `report-template.md`, "Worked example" |
